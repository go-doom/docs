# go-doom docs

Documentation site for the [go-doom](https://github.com/go-doom) organization — built with
MkDocs Material, versioned with [mike](https://github.com/jimporter/mike), served
at <https://go-doom.github.io/docs/>.

```sh
pip install -r requirements.txt
mkdocs serve
```
